# java-racingcar-precourse

## 기능 요구 사항

- 초간단 자동차 경주 게임 구현
- 주어진 횟수 동안 n대의 자동차는 전진 또는 멈출 수 있음
- 각 자동차에 이름을 부여할 수 있으며, 전진 시 자동차 이름과 함께 출력
- 자동차 이름은 쉼표(,)로 구분하며, 이름은 5자 이하만 가능
- 사용자는 이동 횟수를 입력 가능
- 전진 조건: 0에서 9 사이 무작위 값 생성 후, 값이 4 이상일 경우 전진
- 게임 종료 후 우승자 발표, 우승자는 한 명 이상 가능
- 우승자가 여러 명일 경우 쉼표(,)로 구분
- 잘못된 값 입력 시 **IllegalArgumentException** 발생 후 애플리케이션 종료

## 실행 흐름

**1. 프로그램 시작**<br>
**2. "경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)" 안내 문구 출력**<br>
**3. 사용자가 자동차 이름 입력**<br>
**4. "시도할 횟수는 몇 회인가요?" 안내 문구 출력**<br>
**5. 사용자가 시도 횟수 입력**<br>
**6. 자동차 경주 시작**<br>
**7. 각 시도마다 자동차가 랜덤으로 이동 결정**<br>
**8. 각 시도마다 자동차의 현재 위치 출력**<br>
**9. 모든 시도가 끝난 후 우승자 발표**<br>

## 개발 순서

**1. RacingCarGame 클래스 생성** - 게임 로직 관리  
프로그램의 전체 흐름을 제어 <br>
입력 → 실행 → 출력의 과정을 총괄하며 각 클래스와 연동

**2. InputView 클래스 생성** - 사용자 입력 처리  
사용자로부터 자동차 이름과 시도 횟수를 입력 <br>
잘못된 입력 시 예외 처리 수행

**3. Car 클래스 생성** - 자동차 상태와 이동 로직 관리  
자동차 객체를 생성 <br>
이동 로직 구현 <br>
이름 및 현재 위치를 관리

**4. OutputView 클래스 생성** - 경기 결과 출력  
각 시도별 자동차 이동 결과 출력 <br>
최종 우승자를 콘솔에 출력

**5. RaceWinnerChecker 클래스 생성** - 우승자 판별   
제일 멀리간 자동차의 이동 거리 확인 
우승자 리스트를 반환
